# Pokémon Stats Skill

Use the `pokeapi_stats` MCP tool to look up Pokémon base stats and compare stats across Pokémon.

## Usage
- Provide the Pokémon's name in lowercase (e.g., `pikachu`, `charizard`, `mr-mime`).
- The tool calls the PokéAPI via the local MCP server to retrieve base stats (HP, Attack, Defense, Sp. Atk, Sp. Def, Speed).
